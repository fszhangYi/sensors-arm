# Elite EC66（ES66）

## SDK

与 EC616 **共用**现有栈，无需新驱动：

- `elirobots` → `elite.EC` + monitor `machinePos`
- hik-sensors `kind: arm_write` / `arm_read`

真机：配 `robot_ip`，`pip install elirobots`，`dry_run: false`。

## 数模

来自官方 ROS 描述包 [Elite-Robots/ROS](https://github.com/Elite-Robots/ROS) 的 `elite_description`，落在：

`src/sensors_arm/static/models/ec66/`

型号 key：`elite_ec66`（见 `configs/models_catalog.yaml`）。

关节名：`joint1`…`joint6`；默认 offset/signs 全 0/1（官方 URDF 与示教角一致）。若显示拧巴，只改 catalog。

## FK/IK

`sensors.kinematics` 的 DH 按 hik/EC616 工位标定，**不要**把 TCP 叠加当 EC66 真值。关节点动 / Home 走 Elite 关节指令，不依赖该 FK。
