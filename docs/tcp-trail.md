# TCP 轨迹（路点珠 + 色线）

日期：2026-10-10  
状态：**已实现**  
范围：sensors-arm 3D 画布；仿 sensors-dcs 推理位姿画布的 goal trail（珠 + 顶点色折线 + 清除 / 换色）。

---

## 与 DCS 的对应

| DCS | sensors-arm |
|-----|-------------|
| pi05 goal 更新时落点 | **live TCP（FK）** 位移落点；拖拽 IK 时跟琥珀球落点 |
| 粉球 goal 标记 | 无（本项目无推理 goal） |
| 清除轨迹 / 轨迹色 | 画布左侧同款控件 |
| `localStorage` 轨迹色 | `sensors-arm.poseTrailColor` |

---

## 行为

1. TCP 相对上一点移动 ≥ `0.8 mm` 时追加珠与折线（最多 400 点，FIFO）。
2. 换色只影响**之后**新点；已画轨迹保持原色。
3. 「清除轨迹」只清珠与线，琥珀球 / URDF 不动。
4. 切换臂时自动清轨迹，避免串臂。

---

## 验收

1. 连接后 jog / 绝对下发，画布留下 TCP 轨迹。
2. 拖琥珀球时轨迹跟预览位置延伸。
3. 清轨迹按钮悬停展开；换色后新段变色、旧段不变。
