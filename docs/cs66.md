# Elite CS66（口语 ES66）

## SDK（与 EC 不同）

| | Cell A EC616 | Cell B CS66 |
|---|---|---|
| hik-sensors kind | `arm_write` / `arm_read` | **`arm_cs_write`** / `arm_cs_read` |
| Python 包 | PyPI `elirobots` → `elite.EC` | `elite_cs_sdk`（[CS SDK Python](https://github.com/Elite-Robots/Elite_Robots_CS_SDK_Python)） |
| 流式关节 | `TT_add_joint`（度） | `EliteDriver.writeServoj`（弧度） |
| 端口 | 54321 + monitor 8056 | Primary **30001**（+ RTSI 30004） |

详见 hik-sensors [`docs/elite-cs-vs-ec.md`](../../sensors/docs/elite-cs-vs-ec.md)。

配置：`configs/sensors_multi.yaml` 中 `arm-b` 的 `kind: arm_cs_write`。

真机：`dry_run: false`，安装 `elite_cs_sdk`，控制器 CS 固件满足 SDK README；可选配置 `rtsi_output_recipe` 做关节反馈。

## 数模

`src/sensors_arm/static/models/cs66/`

- **关节原点**：按 `sensors.cs66_kinematics` profile `elite_cs66` 的示教 MDH 重建（2026-10-15），与 FK 法兰同构  
- **网格**：仍来自 `CS66urdf.rar`（SolidWorks）；连杆外观可能相对旧导出有毫米级偏差，但法兰/琥珀球应对齐  
- **末端**：法兰后接 **KWR75** + **EFG-C65**（静态网格；CAD `cad/EFG-C65.STEP`）

型号 key：`elite_cs66`（`configs/models_catalog.yaml`）。默认 Cell B 使用此型号。关节名 `joint1`…`joint6`；offset/signs 全 0/1。

## FK/IK

Cell B **不**走 `sensors.kinematics`（EC616 DH），而走：

- `sensors.cs66_kinematics` + profile `elite_cs66`
- 示教 MDH / 软限位 / `teach_poses`（含 2026-10-15 交叉验证点）
- `R_install = I`；profile 法兰 TCP = `[0]*6`
- 交叉验证：有效点位 FK 位置误差约 **0.003–0.005 mm**，IK 关节范数约 **0.04°**

Cell B `tcp_xyz` 默认 **`[0,0,0.1505]`**（法兰→EFG-C65 尖端 ≈ 0.0335+0.117，用于右侧 TCP / 拖拽 IK）。核对示教器法兰位姿时改为 `[0,0,0]`。

**标记球**：琥珀 = MDH FK + `tcp_xyz`；蓝球 = 同 FK、工具偏置 `[0,0,0]`（法兰）。`tcp_xyz=[0,0,0]` 时两球重合。

## 与 EC66

仓库仍保留 `elite_ec66`（GitHub Elite-Robots/ROS 数模，**EC SDK**）。  
工位是 **CS** 系列 → `elite_cs66` + `arm_cs_write`；**EC** 系列 → `elite_ec66` / `elite_ec616` + `arm_write`。
